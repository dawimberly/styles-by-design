# Styles by Design

Custom interiors site for a San Antonio kitchen, bath, and cabinetry studio. Nuxt 3, Tailwind, deployed on Vercel.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

- Site: https://styles-by-design.vercel.app
